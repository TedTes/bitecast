How the categories interact

Technical architecture

Prediction math · implemented pipeline

This is the implemented Python custom-model path. The displayed 0–100 bite score is a relative ranking of conditions—not a percentage chance of catching a fish. The precise family uses one lake-hour; the separate broad fallback uses weather aggregated across an honest trip/time block and never fabricates hourly catch labels. Production serving still requires approved champions, a weather provider, and a deployed forecast worker.

Training · observation influence

Row weight

wᵢ = qualityᵢ × √min(effortᵢ / 60, 1) × contributorᵢ

Higher-quality observations carry more influence. Effort is capped at 60 minutes, and repeated contributors are reduced by inverse square-root frequency.

Variables & parameters +
i
One accepted angler-hour training row.
wᵢ
Final influence assigned to row i during training.
qualityᵢ
Source-quality value for row i, constrained to 0.05–1.00.
effortᵢ
Fishing minutes represented by row i, constrained to 1–60 for weighting.
60
Fixed effort cap; longer trips do not keep increasing one row’s weight.
contributorᵢ
Normalized inverse-square-root frequency weight for that pseudonymous angler; 1 when unavailable.

Training · objective

Weighted binary log loss

L = −Σwᵢ[yᵢ ln(pᵢ) + (1−yᵢ)ln(1−pᵢ)] / Σwᵢ

Each label is catch = 1 or no-catch = 0. CatBoost changes its trees to reduce confident wrong predictions, using the row weights above.

Variables & parameters +
L
Weighted average training error CatBoost minimizes.
Σ
Sum over all training rows.
i
Current training row.
wᵢ
Training influence of row i from the row-weight calculation.
yᵢ
Observed label: 1 for catch, 0 for no-catch.
pᵢ
Model-estimated probability for the observed label in row i.
ln
Natural logarithm; makes confident wrong answers especially costly.

1 · one future lake-hour

Feature transformation

hour → [sin(2πh/24), cos(2πh/24)]

direction → [sin(θ), cos(θ)]

Circular values stay close across their wrap point: 23:00 remains near 00:00, and 359° remains near 0°. Day-of-year is encoded the same way.

Variables & parameters +
h
UTC hour as a decimal from 0 up to 24.
24
Fixed number of hours in one daily cycle.
π
Pi; converts one complete cycle into radians.
θ
Wind direction converted from degrees to radians.
sin, cos
Paired coordinates that preserve position around a circle.
365.25
Cycle length used by the equivalent day-of-year transformation.

2 · CatBoost inference

Three nonlinear tree models

pₘ = sigmoid(bₘ + Σₜ treeₘₜ(x)),   m = 1,2,3

Each tree routes the feature row through learned condition splits. Its leaf value adjusts the model log-odds; the sigmoid converts the total to 0–1.

Variables & parameters +
x
Exact feature row for one future lake-hour.
m
Model index; BiteCast trains three models with different random seeds.
t
Tree index inside model m.
bₘ
Learned baseline log-odds for model m.
treeₘₜ(x)
Learned leaf adjustment returned by tree t after evaluating x.
sigmoid
Function 1 / (1 + e⁻ᶻ), converting log-odds to 0–1.
pₘ
Uncalibrated probability output from model m.

3 · ensemble

Average independent seeds

p̄ = (p₁ + p₂ + p₃) / 3

Averaging makes the prediction less dependent on one random training path. The spread σ(p₁,p₂,p₃) later reduces confidence when models disagree.

Variables & parameters +
p₁,p₂,p₃
Uncalibrated predictions from the three CatBoost seeds.
3
Configured ensemble size in the current implementation.
p̄
Arithmetic mean sent to calibration.
σ
Standard deviation across model predictions; larger means more disagreement.

4 · calibration

Correct the probability scale

p = clip(gisotonic(p̄), 0, 1)

A monotonic function learned on validation data maps ensemble output to observed outcome frequency. It can correct overconfidence without reversing rank order.

Variables & parameters +
p̄
Mean output from the three-model ensemble.
gisotonic
Monotonic piecewise mapping learned from validation predictions and outcomes.
clip
Restricts the result to the inclusive interval 0–1.
p
Calibrated probability used for ranking and evaluation.
0,1
Minimum and maximum valid probability.

5 · product score

Convert probability to relative rank

score = round(100 × #{r ∈ R : r ≤ p} / |R|)

R is the stored lake + season probability distribution, falling back to season and then global history. A score of 92 means conditions rank near the 92nd percentile of that reference—not a 92% catch promise.

Variables & parameters +
p
Calibrated probability for the future lake-hour.
R
Sorted training-probability reference for lake + season, then season, then global fallback.
r
One historical probability stored in R.
#{…}
Count of reference probabilities less than or equal to p.
|R|
Total number of probabilities in the selected reference.
100
Converts the resulting percentile fraction to the 0–100 display scale.
round
Rounds the score to the nearest whole number.

6 · evidence confidence

Coverage + completeness + agreement

C = clip(.45V + .30M + .25A − .08U, 0, 1)

V = clipped ln(1 + lake rows) / ln(501); M = 1 − missing numeric fraction; A = clipped 1 − σ(pₘ)/0.15; U = count of unfamiliar categorical values.

Variables & parameters +
C
Final evidence-confidence score from 0 to 1.
V
Lake coverage: clip[ln(1 + training rows for lake) / ln(501), 0, 1].
M
Numeric completeness: 1 minus the fraction of missing base numeric features.
A
Ensemble agreement: clip[1 − σ(pₘ) / 0.15, 0, 1].
U
Number of categorical values not observed during training.
.45,.30,.25
Fixed weights for coverage, completeness and agreement.
.08
Fixed confidence penalty per unfamiliar category.
500
Lake-row count at which the coverage component reaches its cap.
0.15
Model-disagreement scale at which the agreement component reaches zero.

7 · publication + windows

Decide what the app receives

publish ⇔ C ≥ 0.25   ·   window hour ⇔ score ≥ 65

Confidence labels are High at C ≥ 0.72, Medium at C ≥ 0.45, otherwise Low. Qualifying hours separated by no more than one hour become a forecast window; its maximum is the peak.

Variables & parameters +
C
Evidence-confidence score calculated in the preceding card.
0.25
Minimum confidence required to publish; otherwise the prediction is audit-only.
score
Relative 0–100 conditions rank.
65
Minimum score for an hour to qualify for a forecast window.
0.72
Minimum C for the High confidence label.
0.45
Minimum C for Medium; lower published values are Low.
1 hour
Maximum spacing between qualifying hours in the same window.
peak
Highest-scoring qualifying hour inside the completed window.

8 · reasons

SHAP feature contribution

model output = baseline + Σⱼ φⱼ

The current implementation takes SHAP values from the first ensemble model. The largest reviewed |φⱼ| values become up to three plain-language reasons; their signs show whether each feature pushed the outlook up or down.

Variables & parameters +
baseline
Model output expected before this lake-hour’s individual feature effects are added.
j
Feature index, such as wind, pressure, light or water temperature.
φⱼ
SHAP contribution assigned to feature j for this prediction.
Σⱼ
Sum across all feature contributions.
sign(φⱼ)
Positive pushes the model outlook up; negative pushes it down.
|φⱼ|
Contribution magnitude used to rank potential explanations.
3
Maximum number of reviewed plain-language reasons shown.

Reality check

Measure prediction error

Brier = (1/N) Σᵢ(pᵢ − yᵢ)²

Lower is better. Log loss, calibration error, top-20% lift, lake holdout, and lake/month segments are also reviewed before a challenger can be promoted.

Variables & parameters +
N
Number of evaluated observations.
i
Current evaluated observation.
pᵢ
Calibrated prediction for observation i.
yᵢ
Observed outcome for observation i: catch = 1, no-catch = 0.
(…)²
Squared error, making larger probability mistakes cost more.
Brier
Mean squared probability error; 0 is perfect and lower is better.
20%
Highest-scored fraction used by the separate top-20% lift metric.
